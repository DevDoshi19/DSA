## 1. Why store indices instead of values?

Your deque stores:

Python

Run

```
q = deque([indices])
```

For example:

Python

Run

```
nums = [1, 3, -1, -3, 5]
```

Suppose the deque contains index `1`, meaning value `3`.

We need two pieces of information:

|
Information

|

Why?

|
| --- | --- |
|

Value `3`

|

Compare which value is larger

|
|

Index `1`

|

Know when the element leaves the window

|

The window restriction depends on position, not value.

Imagine:

Python

Run

```
nums = [9, 1, 2]
k = 2
```

The `9` eventually leaves the window. We need its index to know exactly when it expires.

> General rule: Store indices when you need both the element's value and its position (expiry, distance, width, boundaries).

This is why indices are common in monotonic stacks and queues.

## 2. Why `q[0] <= i - k`?

This is the most important part. Let's derive it.

For a window of size `k = 3`, when we're at index `i = 4`, the current window is:

```
Indices: [2, 3, 4]
```

The valid window starts at:

i−k+1=4−3+1=2i-k+1 = 4-3+1 = 2i−k+1=4−3+1=2

Therefore, any index less than 2 has expired.

The last invalid index is:

i−k=4−3=1i-k = 4-3 = 1i−k=4−3=1

So we remove:

Python

Run

```
if q and q[0] <= i - k:
    q.popleft()
```

### Why `q[0]`?

Because the deque's indices remain in increasing order.

The front is the oldest index. If the oldest index is valid, all later indices are also valid.

We only need to check the front.

## 3. Why use `while` to remove from the back?

Your question is excellent:

> "If the first element is greatest, why compare other elements?"

Because we want to remove useless candidates, not just find the maximum.

Consider:

Python

Run

```
nums = [1, 3, 2]
k = 3
```

After processing:

```
Deque indices: [1, 2]
Values:          [3, 2]
```

The deque front is `3`, the maximum.

But `2` is still stored. Is it useful?

No! Because:

* `3` is larger than `2`.

* `3` is older than `2`.

* Both are currently in the window.

* `3` will remain useful at least as long as `2`.

Therefore, `2` can never become the maximum while `3` is present.

We remove it:

Python

Run

```
while q and nums[q[-1]] <= nums[i]:
    q.pop()
```

### Why `while`, not `if`?

Because several smaller elements may exist at the back.

Example:

Python

Run

```
nums = [5, 4, 3, 6]
```

Before processing `6`:

```
Values in deque: [5, 4, 3]
```

When `6` arrives:

1. Remove `3` because `6 > 3`.

2. Remove `4` because `6 > 4`.

3. Remove `5` because `6 > 5`.

4. Insert `6`.

Final deque:

```
[6]
```

The loop removes all dominated candidates.

## 4. The complete mental model 🧠

Think of the deque as:

> A list of candidates that could become the maximum in the current or future windows.

We maintain two properties:

1. Indices are increasing → expiry can be checked from the front.

2. Values are decreasing → maximum is always at the front.

When a new value arrives:

* Remove expired indices from the front.

* Remove smaller or equal values from the back.

* Add the new index.

* Read the maximum from the front.

### Interview note

Python

Run

```
# Store indices because we need both values and positions.
# Remove expired indices using q[0] <= i-k.
# Remove smaller values from the back because they are dominated
# by the new value and can never become the maximum before it expires.
# The deque maintains increasing indices and decreasing values.
# Therefore, q[0] always gives the index of the current maximum.
# Each index enters and leaves the deque at most once.
# Time: O(n), Space: O(k).
```
