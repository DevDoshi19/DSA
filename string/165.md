1. Why your list comparison works
Python compares lists lexicographically, very similar to how words are compared alphabetically.
For example:
[1, 2, 3] < [1, 2, 4]


Python does:
1 vs 1 → equal
2 vs 2 → equal
3 vs 4 → 3 < 4

Therefore:
[1, 2, 3] < [1, 2, 4]


is True.
Example with your versions
num1 = [1, 2, 3]num2 = [1, 2, 4]


Python essentially does:
1 == 1
↓
2 == 2
↓
3 < 4
↓
num1 < num2

So:
num1 > num2


is simply asking Python to perform that lexicographical comparison.
2. What if the first number is different?
[2, 1, 100][3, 0, 1]


Python doesn't care about the later values.
It sees:
2 < 3

and immediately knows:
[2, 1, 100] < [3, 0, 1]


The 100 doesn't matter.
That's exactly how version comparison should work.
